# Cyber Security Lab

## Project Overview
This repository contains cybersecurity practical exercises, laboratory activities and technical experiments completed to develop knowledge of cybersecurity concepts and security practices.

## Tools and Technologies
- Kali Linux
- Windows
- VirtualBox
- Wireshark
- Nmap
- Cisco Packet Tracer

## Topics Covered
- Network Security
- Ethical Hacking Fundamentals
- Vulnerability Assessment
- Network Scanning
- Packet Analysis
- Firewall Configuration
- System Security
- Security Testing
- Cybersecurity Awareness

## Project Objectives
- Develop practical cybersecurity skills.
- Understand common security threats and vulnerabilities.
- Practise network monitoring and security tools.
- Improve technical troubleshooting and analytical skills.
- Explore defensive security techniques.

## Repository Contents
This repository includes laboratory exercises, screenshots, configuration files, practical notes and related learning resources.
